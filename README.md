# razzk — מערכת תיווך טלפונית לאורגניסטים וזמרים

מערכת על ימות המשיח שמתווכת בין בעלי מקצוע (אורגניסטים וזמרים) ללקוחות. **כל הלוגיקה בשרת**; ימות המשיח רק מקשיבה ומשמיעה.

- שרת: Cloudflare Workers (TypeScript + Hono)
- נתונים: Supabase (Postgres)
- אתר ניהול: `/admin` (סיסמה)
- נקודת הכניסה לימות: `/ivr?k=<IVR_SECRET>`

## איך השיחה עובדת

ימות המשיח עושה את רוב העבודה; השרת מטפל רק במה שדורש נתונים או חישוב.

**בימות (בלי פנייה לשרת):** תפריט ראשי, פתיח ואישור תנאים, בחירת סוג בעל מקצוע/בקשה, ההודעה למנהלים (תא קולי), ואיסוף כל התשובות בהרשמות (שלוחות `api` עם `api_000`, `api_001` ...). השאלות כתובות בקובצי `NNN.tts` שבתיקיית `/prompts` בקו.

**בשרת:** ימות שולחת את כל התשובות יחד (עם הפרמטר `flow`). השרת בודק אותן, ושואל רק מה שדורש אישור או נתונים: זיהוי עיר, ימים, הקלטות שכונה/רחוב/פרטים, שעות וטלפונים נוספים, התחייבות. אחר כך שומר, מתאים, ומחזיר לתפריט הראשי (`go_to_folder=/`). האזור האישי (הצעות ובקשות) בנוי כולו בשרת.

| מקש | תפריט ראשי | שלוחה בקו |
|---|---|---|
| 1 | לקוח: בקשת אורגניסט/זמר | `/1` ← `/1/1` ← `/1/1/1`, `/1/1/2` |
| 2 | הרשמת בעל מקצוע | `/2` ← `/2/1` ← `/2/1/1`, `/2/1/2`, `/2/1/3` |
| 3 | אזור אישי | `/3` (flow=personal) |
| 4 | תשלום למערכת | `/4` (flow=pay) |
| 6 | הודעה למנהלים | `/6` (תא קולי, נשמר בקו) |
| 7 | תוכנית שותפים | `/7` (flow=partner) |

כללי הקשה: ספרות ואחריהן `#`. שעה: 4 ספרות. תאריך: 6 ספרות (יום חודש שנה). שמות ועיר: זיהוי דיבור, ואם לא זוהה — מקלדת עברית רגילה של ימות.

## הגדרה בימות המשיח (פעם אחת)

1. צרו שלוחה מסוג `api` (למשל `/1`).
2. בכל שלוחות ה-`api` (`1/1/1`, `1/1/2`, `2/1/1`, `2/1/2`, `2/1/3`, `3`, `4`, `7`) מחליפים את `razzk.invalid` ב-דומיין השרת, ב-`api_link` וב-`api_hangup_link`.
3. מומלץ: `api_hangup_send=yes` ו-`api_hangup_link` לאותה כתובת בתוספת `&hangup=yes` (ניקוי שיחות).
4. צרו בקו תיקיית הקלטות (ברירת מחדל `/recordings`, ניתנת לשינוי באתר הניהול).
5. אחרי אישור מזהה שיחה לצינתוקים — מלאו אותו בהגדרות באתר הניהול והגדירו `YEMOT_TOKEN`.

## פריסה

```bash
npm install
# הרצת מיגרציה: supabase/migrations/001_init.sql (ב-SQL editor של Supabase)
npx wrangler secret put SUPABASE_URL
npx wrangler secret put SUPABASE_SERVICE_KEY
npx wrangler secret put IVR_SECRET
npx wrangler secret put ADMIN_PASSWORD
npx wrangler deploy
```

בדיקה מקומית של שיחות מדומות (בלי רשת): `npm test`.

## ניהול דרך האתר (`/admin`)

האתר הוא המקום המרכזי; הטלפון מתחבר אליו.
- **הוספה ועריכה בטפסים:** בעלי מקצוע (פרטים, ימים, חלונות שעות, תקציב, טלפונים) ובקשות (לקוח, אירוע, תקציב).
- **התאמות:** לכל בקשה מוצגים בעלי המקצוע המתאימים (עיר, יום, שעות, סגנון, הגברה, תקציב), עם כפתור "הצע" וסכום.
- **הצעות:** אישור הצעה מחשב עמלה לפי ההגדרות ומציג את פרטי הקשר.
- **דף "התאמות":** כל הבקשות הפתוחות עם מספר ההתאמות וההצעות.

## מה ניתן לשנות באתר הניהול

עמלה (אחוז, מי משלם, חלוקה), אחוז חריגה, כל נוסחי ההודעות, הפעלת תשלום, ערים (סנכרון ממאגר data.gov.il), ניהול בעלי מקצוע/לקוחות/בקשות/הצעות/שותפים והודעות.

## סטטוס

- ✅ הרשמת בעלי מקצוע ולקוחות, התאמה (עיר, יום, שעות, סגנון, הגברה, תקציב), הצעות, אזור אישי, מחיקה ותיקון, הודעות למנהלים, שותפים (בסיסי)
- ⏳ תשלום וסליקה (כבוי בהגדרות; כרגע פרטי הקשר נמסרים בלי תשלום — לניסויים בלבד)
