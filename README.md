# razzk — מערכת תיווך טלפונית לאורגניסטים וזמרים

מערכת על ימות המשיח שמתווכת בין בעלי מקצוע (אורגניסטים וזמרים) ללקוחות. **כל הלוגיקה בשרת**; ימות המשיח רק מקשיבה ומשמיעה.

- שרת: Cloudflare Workers (TypeScript + Hono)
- נתונים: Supabase (Postgres)
- אתר ניהול: `/admin` (סיסמה)
- נקודת הכניסה לימות: `/ivr?k=<IVR_SECRET>`

## איך השיחה עובדת

שלוחה אחת מסוג `api` בימות. בכל הקשה ימות פונה לשרת עם כל הנתונים, והשרת מחזיר את השאלה הבאה (פקודת `read`). המצב נשמר בטבלת `sessions` לפי מזהה השיחה.

| מקש | תפריט ראשי |
|---|---|
| 1 | אני צריך אורגניסט / זמר (לקוח) |
| 2 | אני אורגניסט / זמר (הרשמת בעל מקצוע) |
| 3 | אזור אישי (לקוח: הצעות; בעל מקצוע: בקשות מתאימות) |
| 4 | תשלום למערכת |
| 6 | השארת הודעה למנהלים |
| 7 | תוכנית שותפים |

כללי הקשה: ספרות ואחריהן `#`. שעה: 4 ספרות. תאריך: 6 ספרות (יום חודש שנה). בכל שדה: `1` אישור, `2` תיקון.
שמות: זיהוי דיבור; אחרי כשלונות — מקלדת עברית רגילה של ימות.

## הגדרה בימות המשיח (פעם אחת)

1. צרו שלוחה מסוג `api` (למשל `/1`).
2. `api_link=https://<הדומיין שלכם>/ivr?k=<IVR_SECRET>`
3. מומלץ: `api_hangup_send=yes` ו-`api_hangup_link` לאותה כתובת בתוספת `&hangup=yes` (ניקוי שיחות).
4. צרו בקו תיקיית הקלטות (ברירת מחדל `/recordings`, ניתנת לשינוי באתר הניהול).
5. אחרי אישור מזהה שיחה לצינתוקים — מלאו אותו בהגדרות באתר הניהול והגדירו `YEMOT_TOKEN`.

## פריסה

```bash
npm install
# הרצת מיגרציה: supabase/migrations/001_init.sql (ב-SQL editor של Supabase)
npx wrangler secret put SUPABASE_URL
npx wrangler secret put SUPABASE_SERVICE_KEY
npx wrangler secret put IVR_SECRET
npx wrangler secret put ADMIN_PASSWORD
npx wrangler deploy
```

בדיקה מקומית של שיחות מדומות (בלי רשת): `npm test`.

## מה ניתן לשנות באתר הניהול

עמלה (אחוז, מי משלם, חלוקה), אחוז חריגה, כל נוסחי ההודעות, הפעלת תשלום, ערים (סנכרון ממאגר data.gov.il), ניהול בעלי מקצוע/לקוחות/בקשות/הצעות/שותפים והודעות.
