# תסריט קריינות — מערכת התיווך

כל ההודעות מושמעות כרגע בקול ממוחשב של ימות המשיח (קבצי `.tts`). להקלטה אנושית: מקליטים כל הודעה, ומעלים לקו את הקובץ בשם ובנתיב שמצוין, כקובץ `.wav`.
לשינוי נוסח בלי הקלטה: עורכים את קובץ ה-`.tts` באותו נתיב. ההודעות שהשרת משמיע ניתנות לעריכה באתר הניהול (הגדרות והודעות).

## תפריטים (בקו)

| נתיב | נוסח |
|---|---|
| `/M1000` (תפריט ראשי) | ברוכים הבאים למערכת התיווך לאורגניסטים וזמרים. לבקשת אורגניסט או זמר הקישו 1. להרשמה כאורגניסט או זמר הקישו 2. לאזור האישי הקישו 3. לתשלום הקישו 4. להשארת הודעה למנהלי המערכת הקישו 6. לתוכנית השותפים הקישו 7. |
| `/1` (לקוח: פתיח ותנאים) | ברוכים הבאים לבקשת אורגניסט או זמר. הזינו את פרטי האירוע, והמערכת תפנה לבעלי מקצוע מתאימים. האם אתם מאשרים ומקבלים עליכם את תנאי המערכת? לאישור הקישו 1. לסירוב הקישו 2. |
| `/2` (בעל מקצוע: פתיח ותנאים) | ברוכים הבאים להרשמת בעלי מקצוע. המערכת מקשרת בין בעלי מקצוע ללקוחות. בעל מקצוע שיסגור עסקה דרך המערכת מתחייב לשלם את העמלה שנקבעה. האם אתם מאשרים ומקבלים עליכם את תנאי המערכת? לאישור הקישו 1. לסירוב הקישו 2. |
| `/1/1` (לקוח: סוג בקשה) | לבקשת אורגניסט בלבד הקישו 1. לאורגניסט וזמר הקישו 2. לחזרה הקישו 9. |
| `/2/1` (בעל מקצוע: סוג) | לאורגניסט בלבד הקישו 1. לאורגניסט וזמר הקישו 2. לזמר בלבד הקישו 3. לחזרה הקישו 9. |

## הודעות שהשרת משמיע (עריכה באתר הניהול ← הגדרות והודעות)

אישורי תיקון והקראה ("לאישור הקישו 1, לתיקון הקישו 2"), הצעות ללקוח, בקשות לבעל מקצוע, אישור ההצעה, חישוב העמלה, וכן הודעת "התשלום יופעל בקרוב".
